## Capture checklist

- [ ] 1920×1080 or 2560×1440 canvas
- [ ] Cursor highlight visible but not distracting
- [ ] No passwords, tokens, email, bookmarks, or unrelated tabs
- [ ] Codex tool names readable at least once
- [ ] State version readable before and after the human edit
- [ ] Human authorization click captured in real time
- [ ] No edit suggests the agent performed the human-only click
- [ ] S3 visibly remains open after execution
- [ ] Narration is audible, paced, and matches the captured result
- [ ] Final runtime is under 3:00
- [ ] Upload is Public on YouTube, not Unlisted if the rules require Public
- [ ] Live URL and repository are visible and verified

## Optional raw footage

If automated screen recording is unavailable, capture silent raw footage in the same sequence and use `transcript.md` for later voiceover. Silent raw footage alone does **not** satisfy the challenge's public-video-with-audio requirement.
